# branch-diff Specification

## Purpose
定义 Agent-Inspect 的分支并排 diff 能力:将同一 trace 下的两个分支按决策点对齐,给出每个步骤的对照状态(相同 / 差异 / 仅一侧),并提供字段级差异明细与汇总计数,使开发者可精确观察"从分歧点起,在哪一步、哪个字段发生了变化"的可观测行为。

## Requirements

### Requirement: 分支步骤对齐与状态
系统 SHALL 对同一 trace 下的任意两个分支按决策点对齐,并为每个对齐后的步骤给出对照状态:相同 / 差异 / 仅左侧 / 仅右侧。

#### Scenario: 共享前缀步骤为相同
- **WHEN** 比较具有共享前缀的两个分支
- **THEN** 位于两分支共享前缀中的每个步骤均标记为"相同"

#### Scenario: 分叉后输出不同标记为差异
- **WHEN** 两个分支在分叉点之后的同一步骤产生不同输出
- **THEN** 该步骤标记为"差异"

#### Scenario: 仅一侧存在的步骤
- **WHEN** 某步骤只存在于其中一个分支
- **THEN** 该步骤标记为"仅左侧"或"仅右侧",另一侧不出现该步骤

### Requirement: 字段级差异明细
系统 SHALL 对标记为"差异"的步骤给出字段级明细,指明输入或输出内具体路径的左右取值,或在字段仅一侧存在时明示。

#### Scenario: 输出字段差异
- **WHEN** 两个分支同一步骤的输出在同一字段取值不同
- **THEN** 明细中列出该字段路径及左右两侧的取值

#### Scenario: 输入字段差异
- **WHEN** 两个分支同一步骤的输入在同一字段取值不同
- **THEN** 明细中列出该输入字段路径及左右两侧的取值

#### Scenario: 字段仅一侧存在
- **WHEN** 一个字段仅存在于其中一个分支的决策点
- **THEN** 明细以该字段在另一侧缺失的形式呈现,而非静默忽略

#### Scenario: 嵌套结构差异可定位
- **WHEN** 差异位于多层嵌套的对象或数组内部
- **THEN** 明细中的字段路径可定位到具体嵌套位置

### Requirement: 差异汇总
系统 SHALL 提供一次比较的汇总统计,包含相同 / 差异 / 仅左侧 / 仅右侧四类步骤计数。

#### Scenario: 汇总计数与步骤一致
- **WHEN** 完成一次两分支比较
- **THEN** 返回各状态步骤的计数,且四类计数之和等于对齐后的总步骤数

### Requirement: 并排视图呈现
系统 SHALL 在面板并排呈现两个分支的决策链,依据 diff 结果区分节点,并在选中差异步骤时展示字段级明细。

#### Scenario: 并排对照呈现
- **WHEN** 面板中选择两个分支并请求对照
- **THEN** 两个分支的决策链并排展示,共享前缀与各自后缀可对照阅读

#### Scenario: 差异节点可识别
- **WHEN** 并排呈现存在差异与仅一侧步骤的两个分支
- **THEN** 差异步骤与仅一侧步骤在链上以不同标记区分,一致步骤不标注差异

#### Scenario: 选中差异步骤查看字段明细
- **WHEN** 在并排视图中选中一个差异步骤
- **THEN** 面板展示该步骤输入与输出上的字段级差异明细

### Requirement: 共享前缀应判定为 same

系统 SHALL 在比较两条分支时,把来自共同祖先的同一决策点判定为 same,而不是因为后续输入上下文被连带修改就标为 diff。

#### Scenario: 祖先前缀标为 same

- **WHEN** 比较一条父分支与从其 step1 分出的 fork 分支
- **THEN** step0 显示为 same(左右来自同一来源分支的同一步骤)

#### Scenario: 分叉后缀才标为 diff

- **WHEN** 比较父分支与 fork 分支
- **THEN** 只有 fork 点开始(step1 及之后)的步骤才参与内容比较并可能标为 diff

#### Scenario: 独立分支仍按内容比较

- **WHEN** 比较两条没有继承关系的分支(如两条都独立的 root 分支)
- **THEN** 按 kind/output/input_context 内容比较,不短路

### Requirement: 对齐步骤列表视图

系统 SHALL 在选中对比分支后,以按 step_index 对齐的垂直列表展示每个步骤,左右两侧分别显示主分支与对比分支的决策点摘要。

#### Scenario: 每行展示左右决策点

- **WHEN** 用户在 diff 视图中查看某一步
- **THEN** 该行左侧显示主分支该 step 的 kind/output 摘要,右侧显示对比分支对应摘要

#### Scenario: 仅一侧存在步骤

- **WHEN** 某 step_index 只存在于一个分支
- **THEN** 另一侧显示空白占位,并标为 only_left / only_right

#### Scenario: 差异步骤高亮

- **WHEN** 某步骤状态为 diff
- **THEN** 该行边框或背景使用差异色,提示用户可点击展开字段明细

#### Scenario: 点击差异步骤查看字段明细

- **WHEN** 用户点击一个 diff 步骤
- **THEN** 右侧面板显示该步骤 input_context + output 的字段级 diff
