# trace-search Specification

## Purpose
对一条已记录 trace 的全部分支按内容子串(大小写不敏感)搜索决策点的输入与输出,返回命中位置与上下文片段,解决"长链路里找哪一步提到了 XX"的回溯检索需求;面板提供搜索入口并支持点击命中直接定位。

## Requirements

### Requirement: 按内容搜索决策点

系统 SHALL 支持在一条 trace 的全部分支内按子串搜索决策点(大小写不敏感),输入与输出均参与匹配,结果标注命中位置与上下文片段。

#### Scenario: 输入与输出参与匹配

- **WHEN** 某决策点的输入或输出内容包含查询子串
- **THEN** 该决策点出现在结果中,标注所在分支、步骤号、命中来源(输入或输出)与包含命中处的上下文片段

#### Scenario: 大小写不敏感

- **WHEN** 查询子串的大小写与决策点内容不一致
- **THEN** 仍然命中

#### Scenario: 无命中返回空

- **WHEN** 没有任何决策点包含查询子串
- **THEN** 返回空结果集

### Requirement: 搜索入口可观测

系统 SHALL 提供面板与 API 的搜索入口,异常请求给出可观测原因。

#### Scenario: 面板搜索并定位

- **WHEN** 在面板对当前 trace 输入查询
- **THEN** 展示命中列表;点击某命中后面板定位到该决策点——必要时切换到其所在分支——并显示完整输入输出;清空查询后结果收起

#### Scenario: 异常请求可观测拒绝

- **WHEN** 对不存在的 trace 发起搜索,或未提供查询子串
- **THEN** 分别返回 404 / 422 与可观测原因
