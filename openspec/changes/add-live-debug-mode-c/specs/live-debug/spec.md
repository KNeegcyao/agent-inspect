## Purpose

定义 Agent-Inspect 的活体调试能力(Mode C):面板可附加到运行中的 Agent 执行,设置条件断点、随时暂停、按决策点步进与继续,并在暂停点检查或修改输入,使开发者能在"执行中"而非"事后"干预 Agent 的可观测行为。

## ADDED Requirements

### Requirement: 附加运行中的执行
系统 SHALL 允许面板附加到一条运行中的 live trace,该执行持续推进并实时追加决策点,直至被暂停或命中断点。

#### Scenario: 附加进行中 trace
- **WHEN** 对一条 running 状态的 trace 发起附加
- **THEN** 该 trace 继续执行,新产生的决策点实时可见,既有已记录决策点保持可读

#### Scenario: 附加不改变执行
- **WHEN** 面板附加期间 Agent 正常推进
- **THEN** Agent 的执行行为不被阻塞或改变,附加仅为观察与调试通道

#### Scenario: 附加后设断点生效
- **WHEN** 附加到运行中的 trace 后设置断点
- **THEN** 后续执行在命中该断点的决策点处暂停

### Requirement: 条件断点
系统 SHALL 允许在决策点上设置条件断点,按决策点类型(LLM/工具)或输入内容判定是否暂停。

#### Scenario: 按类型设断
- **WHEN** 设置命中条件为"LLM 决策点"的断点
- **THEN** 每个 LLM 决策点触发暂停,工具决策点不触发

#### Scenario: 按输入内容命中
- **WHEN** 断点条件为"输入包含指定内容"
- **THEN** 仅当决策点输入满足该条件时暂停,不满足时继续执行

#### Scenario: 条件不命中继续
- **WHEN** 执行经过不满足断点条件的决策点
- **THEN** 该决策点正常执行,不暂停、不产生额外延迟

### Requirement: 暂停与继续
系统 SHALL 允许对运行中的 live trace 发起暂停,暂停发生在决策点边界;暂停后可继续执行至下一断点或完成。

#### Scenario: 手动暂停
- **WHEN** 对运行中的 trace 发起暂停
- **THEN** 执行在下一个决策点边界处停下,不打断当前进行中的调用

#### Scenario: 暂停后继续
- **WHEN** 在暂停状态发起继续
- **THEN** 执行恢复推进,直至下一个断点、新的暂停请求或 trace 完成

#### Scenario: 完成态可见
- **WHEN** 一条 live trace 正常完成
- **THEN** 其生命周期转为完成,面板呈现其完整决策链

### Requirement: 按决策点步进
系统 SHALL 允许在暂停状态下单步执行,一次执行恰好一个决策点后再次暂停。

#### Scenario: 单步执行一个决策点
- **WHEN** 在暂停状态发起单步
- **THEN** 恰好执行下一个决策点后在新的暂停点停下,可检查其输入输出

#### Scenario: 步进不改未经过点
- **WHEN** 单步推进
- **THEN** 未经过的决策点不被执行,既有记录与其它分支不被改变

### Requirement: 暂停点检查
系统 SHALL 在暂停点展示该决策点的完整输入与输出,供调试检查。

#### Scenario: 查看完整输入
- **WHEN** 在暂停的决策点请求查看输入
- **THEN** 展示该决策点的完整输入(LLM 决策点为完整 prompt,工具决策点为完整参数)

#### Scenario: 查看输出状态
- **WHEN** 在暂停的决策点请求查看输出
- **THEN** 展示该决策点已产生的输出;若尚未执行则明示为待执行状态

### Requirement: 暂停处修改后继续
系统 SHALL 允许在暂停的决策点处替换其输入后继续,使该决策点以修改后的输入执行。

#### Scenario: 修改待执行输入
- **WHEN** 在暂停的决策点替换其输入并继续
- **THEN** 该决策点以修改后的输入真实执行,后续决策点据此演化

#### Scenario: 不改直接继续
- **WHEN** 在暂停的决策点不做修改直接继续
- **THEN** 该决策点以原输入执行

### Requirement: 调试作用域隔离
系统 SHALL 使断点、暂停、步进与暂停处修改仅作用于被调试的 trace 与分支,不影响其它并发执行。

#### Scenario: 断点不影响其它 trace
- **WHEN** 对一条 trace 设置断点或暂停
- **THEN** 其它 trace 的 Agent 执行不因此暂停或改变

#### Scenario: 修改仅影响当前执行
- **WHEN** 在某分支的暂停处修改输入
- **THEN** 其它分支与其它 trace 的执行不受该修改影响
